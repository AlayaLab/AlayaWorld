#
# This is deliberately separate from the repository's own requirements.txt, which
# states lower bounds for training and the offline inference paths. A served
# image wants the opposite: exact versions, so the container that streams to a
# client today is the one that streams tomorrow. It also wants headless OpenCV,
# since nothing in the image opens a window.
#
